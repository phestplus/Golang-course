# University-Level Golang (Go) Curriculum – 2026 Edition

## Prerequisites & Preparation

1. Computer Programming Fundamentals (variables, loops, functions)
2. Basic understanding of data structures (arrays, lists, hash maps)
3. Familiarity with operating systems, file systems, and networking concepts
4. Optional: Prior exposure to C, C++, Java, or Python is helpful
5. Recommended tools: VSCode, GoLand, Git, terminal/shell basics
6. Preparatory exercises: Build small scripts in Python or Java to solidify loops, functions, and I/O
